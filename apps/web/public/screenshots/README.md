# Screenshots

Place your screenshots here:

1. `dashboard.png` - Full dashboard view
2. `code-editor.png` - Code editor with generated code
3. `agents.png` - AI agents status panel
4. `output.png` - Generated code output

## How to create screenshots:

1. Start the development server: `npm run dev`
2. Navigate to `/dashboard`
3. Take screenshots using:
   - Browser DevTools (F12 → Screenshot)
   - macOS: Cmd+Shift+4
   - Windows: Snipping Tool or Win+Shift+S
   - Linux: Screenshot tool

## Recommended dimensions:
- Width: 1600px
- Height: 900px (or maintain aspect ratio)
- Format: PNG for best quality

## Tips:
- Use full-screen browser window
- Hide browser UI for cleaner screenshots
- Capture different views (chat, editor, status)
- Show actual generated code if possible
